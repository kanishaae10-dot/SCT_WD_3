
# SCT_WD_3 - Quiz Game Application

## About the Project
An interactive multiple-choice quiz game developed as Task 03
of the SkillCraft Technology Web Development Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Welcome screen and interactive quiz interface
- Single-choice questions
- Multi-select questions
- Fill-in-the-blank questions
- Answer validation and instant feedback
- Progress bar and question counter
- Automatic score calculation out of 100
- Correct and incorrect answer statistics
- Answer review at the end of the quiz
- Retry option to play again
- Responsive design for desktop and mobile devices

## How to Run
1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server.
4. Click Start Quiz and answer the questions.
5. View your score and review your answers.
